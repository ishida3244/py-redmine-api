## 1. ドンちゃっと生成プロンプト

> 現在、Microsoft365のアプリケーションをAWS上(ECS、EC2など)で開発・運用し、GitHubでソースとCI/CD(Actions)を管理しています。開発・運用のクラウドをAWSからAzureに移行した場合、例えばサービス間での認証情報やデータ交換などの複雑なフローをどのように簡素化できますか？またそれによってセキュリティリスクをどのように削減できますか？

> Azureへの移行に大きなメリットがあるとご回答いただき、安心しました。次に、Azure導入の稟議書をIT知識の無い経営層に読んでもらうために、専門用語を使わない数行の短い文章にまとめることはできるでしょうか？

> 次に、Azure導入のメリットをIT知識の無い経営層に分かりやすく示すための図と提案資料をPowerPointで作ってください。

> .pptx を作ってください

> pptxファイルのページ6「全体イメージ（分かりやすい流れ）」はとても分かりやすいです。これはAzure導入後の図ですが、現状(AWSで開発・運用)がいかに複雑でセキュリティ的に危険かを示す図を追加していただけるでしょうか
